Install Build 857

Open this page in desktop Chrome or Edge. Connect one powered FM-1 by USB and close other MIDI apps. Save a backup of anything you need before installing. Keep the instrument powered and this page open until it confirms the restart.

Coming from BB1? Telegram asks before its first library save replaces BB1’s factory sound bank. You can play without saving to the library.

Back up your current instrument before installing. If you need a physically verified return to factory V15, keep your current firmware for now.
